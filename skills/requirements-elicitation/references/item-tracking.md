# Item tracking

Use for issues, concerns, assumptions, constraints, dependencies, defects and improvements that arise during elicitation (BABOK 10.26, pp. 294–295). Attributes; each item may use all or some:
Code, summary, category, type, date raised, raised by, impact (time/cost/scope/quality), priority, resolution deadline, owner, handler, agreed strategy (accept, pursue, ignore, mitigate, avoid), status (open, assigned, resolved, cancelled), update log, escalation matrix.
BABOK caution: recording too much can overwhelm the benefit; keep only the attributes someone actually uses.
Suggested short form: Code | Type | Description | Raised by/date | Owner | Deadline | Status.
