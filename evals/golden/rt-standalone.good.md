Verification method per requirement (ISO/IEC/IEEE 29148, clause 6.5.2.2 names four methods):

| Requirement | Verification method | Why |
|---|---|---|
| REQ-01 | Test | The behaviour is observable: confirm a booking and check the confirmation |
| REQ-02 | Demonstration | Show the reminder arriving the day before, without measuring anything |
| REQ-03 | Inspection | Examine the storage configuration and documents for encryption |

The four methods:
- Inspection: examine documents, code or configuration against the requirement.
- Analysis: use modelling, calculation or simulation instead of running the system.
- Demonstration: show qualitatively that the system behaves as required, with few instruments.
- Test: run the system under controlled conditions and measure the result.

More on 29148 is in the requirements-review skill, if installed. Record the method when the requirement is created, and never reuse a requirement code.
